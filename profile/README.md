**How a project goes**: idea → brief (the founder's go) → reconnaissance → build → quality → security → release (the founder's approval) → share (posts on [blok](https://blok.storagebits.workers.dev), reviewed by the founder) → retro. Every public repository here carries at least one commit by the founder, and every post says which model drafted it.

*Create. Share. Explore. Love. — not necessarily in that order.*
